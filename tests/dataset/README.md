# BSI TR-03105-5 Reference Dataset

Test data from the BSI (German Federal Office for Information Security)
TR-03105-5 conformance test specification for eMRTDs.

Source: BSI TR-03105-5 ReferenceDataSet, included in the BSI test suite
distribution for ICAO 9303 compliance testing.

## Contents

- `Datagroup1.bin` — MRZ data (93 bytes)
- `Datagroup2.bin` — Encoded face image (15 KB)
- `Datagroup3.bin` — Encoded fingerprint (32 KB)
- `Datagroup4.bin` — Encoded iris image (13 KB)
- `Datagroup14.bin` — Chip Authentication public key info (334 bytes)
- `Datagroup15.bin` — Active Authentication public key info
- `EF_SOD.bin` — Document Security Object (CMS SignedData, RSA-PSS-SHA256)
- `EF_COM.bin` — Common data listing present DGs
- `DG14_pk.bin`, `DG14_sk.pkcs8` — Chip Authentication keypair
- `DG15_pk.bin`, `DG15_sk.pkcs8` — Active Authentication keypair

## Notes

The SOD is signed by a DS certificate (HJP PB DS) whose CSCA is not publicly
available. This means steps 1+2 of Passive Authentication can be tested (SOD
signature + DG hash verification), but not step 3 (cert chain to CSCA).

For full e2e Passive Authentication, use the synthetic dataset generated by
`../gen-synthetic-dataset.sh`, which re-signs these DG hashes with a fresh
CSCA + DS keypair.
